# HospitalEmergencyRoomAnalysis-PowerBI-
This project is an interactive Hospital Emergency Room Dashboard developed using Microsoft Power BI. The dashboard is designed to monitor emergency room performance, analyze patient trends, track waiting time and satisfaction, and provide insights into patient admissions, demographics and department referrals.

# Project Objectives

Monitor emergency room patient volume
Analyze average patient wait time
Track patient satisfaction
Compare admitted and non-admitted patients
Analyze patient demographics
Analyze department referral patterns
Identify patient volume trends by day and hour
Generate actionable insights for emergency room operations

# Tools & Technologies

Microsoft Power BI
Power Query
DAX
Data Modeling
Data Transformation
Data Visualization
CSV Dataset

# Dashboard Pages

1. Monthly View
   
Provides month-by-month monitoring of emergency room performance.

Key analysis includes:

Patient Admission Status
Patient Age Distribution
Department Referrals
Patients Seen Within 30 Minutes
Gender Analysis
Racial Demographics
Patient Volume by Day & Hour

2. Consolidated View
   
Provides an overall summary of emergency room performance across a selected date range.

3. Patient Details
   
Provides detailed patient-level information and analysis.

4. Key Takeaways

Summarizes important patterns, anomalies and operational insights identified from the dashboard.

# Key KPIs

Number of Patients
Average Wait Time
Patient Satisfaction Score
Number of Patients Referred

The dashboard uses daily trends and KPI visualizations to monitor emergency room performance.
